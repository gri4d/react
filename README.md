# @gri4d/react
React component for "@gri4d/griiiid".

## Install
```
npm i -S @gri4d/react
```

## How to Use
```javascript
import ReactGRi4D from "@gri4d/react";

<ReactGRi4D {...props} />
```
See <a href="https://github.com/gri4d/react/blob/main/dev/esm-react-esbuild.tsx" target="_blank">https://github.com/gri4d/react/blob/main/dev/esm-react-esbuild.tsx</a> for example.
